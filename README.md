# SyntaxWaer — Landing Page de E-commerce

Um site estático de demonstração para uma loja de tênis / sneakers com layout responsivo, navegação principal, seção "hero", categorias de produto, grid de produtos e rodapé com newsletter e links sociais.

---

## 🚀 Visão Geral

- Projeto front-end estático (HTML + CSS)
- Sem dependências de build / JavaScript (apenas HTML e CSS)
- Focado em layout responsivo e design moderno para lojas de tênis

---

## ▶️ Como visualizar (rodar localmente)

1. Abra a pasta do projeto.
2. Abra o arquivo `index.html` no seu navegador (duplo clique ou arrastando para uma aba).

> 💡 Para desenvolvimento, use uma extensão de servidor local (Live Server, etc.) para evitar problemas com caminhos relativos e oferecer recarga automática.

---

## 🗂 Estrutura de pastas

- `index.html` — página principal do site.
- `css/` — estilos do site.
  - `reset.css` — reset básico de estilos.
  - `componets/` — estilos divididos por componente (header, hero, categorias, grid, footer, etc.).
- `img/` — imagens usadas no layout.
  - `banners/` — imagens de hero (versão mobile / desktop).
  - `icons/` — ícones SVG (menu, redes sociais, carrinho, usuário, etc.).
  - `logo/` — logotipo do site.
  - `products/` — imagens de produtos usadas no grid e categorias.

---

## 🎨 Personalizando o projeto

### 📌 Textos e conteúdo
- Edite o HTML em `index.html` para atualizar títulos, descrições, links e seções.

### 🎨 Cores e tipografia
- Modifique variáveis de CSS em `css/componets/variable.css`.

### 🖼 Imagens e ícones
- Substitua as imagens em `img/` mantendo os mesmos nomes ou atualize os `src` em `index.html`.

---

## 🔧 Dicas rápidas

- **Responsividade**: Teste em diferentes tamanhos de tela (mobile / tablet / desktop).
- **Validação HTML/CSS**: Use ferramentas como o [W3C Validator](https://validator.w3.org/) para garantir conformidade.
